# WeChatAI · 群聊伴读

macOS 原生微信阅读助手，支持群聊和私聊。读取本人微信已同步的本地记录，把选定会话和时间范围交给兼容 Chat Completions 的模型问答。

当前版本：**0.5.2 build 21**。修复输入法候选框停留在其他桌面的问题，补齐 Command+A/C/V/X/Z 与重做的原生编辑菜单。验证报告见 `docs/verification-0.5.2/readiness.json`。

## 使用方式

- 双击 `artifacts/群聊伴读.app`。应用只在微信聊天窗口旁显示气泡，点击展开浮窗；连接、设置和原消息使用辅助窗口。
- 应用作为菜单栏工具运行，不出现在 Dock 或 Command+Tab 中；可通过菜单栏气泡图标打开伴读、连接、设置或退出。原生输入法候选窗口随当前浮窗所在桌面显示。
- 展开和收起有短过渡，遵循 macOS“减少动态效果”。点回微信、切到其他应用或另一个微信窗口会收起；菜单、会话选择器和设置不会误触收起。图片等非聊天窗口不显示气泡。
- 群聊和私聊统一出现在会话选择器中。列表只包含本地消息表中确有记录的会话，不把仅有共同群的成员资料当作私聊。
- 微信自身的独立聊天窗口可按系统窗口标题自动跟随，精确保留 emoji、空格和标点。同名、未匹配或窗口切换时暂停发送。**主窗口内部切换会话仍须手选**。正式应用不含截图/OCR、不需要屏幕录制，也不读取微信运行内存。
- **Return 发送；⌘Return 或 ⇧Return 换行。** 输入法候选优先确认，多行粘贴保留。生成中可以编辑下一条草稿，不能重复提交。
- 输入框、设置输入项和可选中的回答文字使用 macOS 标准编辑命令；支持 ⌘A 全选、⌘C 复制、⌘V 粘贴、⌘X 剪切、⌘Z 撤销和 ⇧⌘Z 重做。
- **新对话**清空当前会话的 AI 回答、草稿、上下文和参考快照；生成中使用会先取消当前请求。会话、时间范围和连接配置保留，不删除微信记录；切走再返回不会恢复被清空的内容。
- 当前进程内按会话保留回答与草稿，收起不清空。退出或重启前请复制需要长期保存的内容。

## 连接与模型

已有本机密钥时自动连接，暂时失败只做有限重试。首次配置在连接页完成账号选择，并通过“高级与诊断”导入逐库密钥清单。初次建立读取权限的流程另有明确说明与确认；本助手不会自动操作微信或重新取钥。

在“外观与设置 → AI 服务 → 服务配置”中填写完整接口地址、模型名称和 API Key，并明确允许将所选记录发送到该服务。服务若本身不要求密钥可留空。“保存并测试（无聊天）”只验证模型服务，不发送聊天记录。

模型回答支持 SSE 流式输出，可停止生成；失败或中断保留已收到的文字，首段前停止会恢复提问。也支持返回普通 JSON 的服务，此时响应一次显示。Markdown 支持标题、强调、列表、引用、代码和表格；代码可复制，不执行 HTML 或加载远程图片。

时间范围包括 15/30 分钟、1/3/5/12 小时、1/3/7 天和自定义。首问按当时范围读取快照，追问沿用快照；“新对话”或“更新记录”使下一次提问重新读取。没有静默截断聊天记录或自动多轮摘要；超出模型容量时需缩短范围或更换模型。

## 外观与数据

外观可选“跟随系统”“浅色”“深色”。跟随系统指跟随 Mac 外观；微信也跟随系统时两者同步，微信单独设置主题时可手动选择匹配外观。

数据库与模型密钥使用**本机普通文件**，目录为 `~/Library/Application Support/cn.local.ChatFloat/credentials`，目录权限 `0700`、文件权限 `0600`。文件不额外加密；能访问当前 Mac 用户文件的程序也可能读到它们。应用不使用钥匙串，不提供旧钥匙串迁移、兼容或回退逻辑，不会为读取密钥请求系统认证。初次使用在应用内填写或导入所需密钥。

账号之间、模型服务之间的密钥分别保存；文件原子替换，删除一项不影响其他项。清理导入记录不删除连接密钥。配置、密钥、聊天记录和构建私钥均不进入源码或应用分发包。

微信数据库访问仍需“完全磁盘访问”，浮窗定位和窗口标题跟随仍需辅助功能权限。这两项系统权限与密钥存储分开管理。

## 消息与图片

支持普通文字、图片、引用回复、卡片/链接及合并转发内可读文字。引用和转发带独立来源标记，不当作当前发送者的新发言；不跨群或超出范围寻找引用来源。语音、表情、系统消息及无法解析的类型计入略过数，不做语音转写。

“允许发送图片”默认关闭。开启后仅准备所选会话与范围内的本地附件，支持普通图片、旧式 XOR DAT 和可从本机元数据获得密钥的 V2 DAT。原图缺失时可退回可解码缩略图，并说明缺失或缩略图状态。

图片最长边缩至 1536 像素后附入多模态请求；默认总预算 20 MB，可调 1–100 MB。单个本地文件读取上限 40 MB，批量读取预算最高 400 MB。未附上的图片有计数与原因，不阻断文字问答。

## 开发与构建

- `Sources/ChatCore`：时间快照、模型请求、凭据文件、导入与 Markdown 数据。
- `Sources/ChatFloat`：AppKit/SwiftUI 界面、窗口跟随和数据库连接。
- `Backend`：SQLCipher 只读查询与图片解码。
- `Checks`、应用内显式检查参数：合成测试，正式界面没有模拟对话入口。
- `artifacts`：唯一当前运行应用、分发压缩包及 `SHA256.json`。
- `work`、`.build`：本机中间产物，不分发。

构建使用 Command Line Tools、SwiftPM、Python，以及 Homebrew 的 sqlcipher、zstd、openssl@4；脚本把所需动态库放入应用，不要求安装完整 Xcode。

固定的本机签名材料独立保存在 `~/Library/Application Support/cn.local.ChatFloat.build-signing`。初次创建后，构建只复用它；身份缺失或不一致会停止，不能自动换证书或退回临时签名。它用于本机开发更新的身份连续性，不能替代公开分发所需的 Apple Developer ID 与公证。

```sh
./scripts/check.sh
# 仅首次建立本机构建身份；已建立时不要重复执行：
python3 scripts/local-signing.py setup
python3 scripts/local-signing.py check
# 之后每次构建只复用现有身份：
./scripts/build-app.sh
```

构建在临时目录完成签名和验证后才替换输出，失败或可处理的中断会保留旧包。构建完成后不修改应用包内容。

本机已实测 build 20 → 20.1 → 20：构建编号和代码签名哈希改变，固定证书身份保持一致，完全磁盘访问和辅助功能权限均保留。此测试只改变包元数据；另有两份不同机器码程序的签名身份交叉校验。未测试公开分发或其他 Mac。

0.5.2 的输入修复使用独立合成界面验证，包括系统中文候选框、普通与全屏桌面、收起重开及真实编辑快捷键。本轮未启动正式应用，也未操作或读取微信；安装后保持关闭，微信内的最终手动复核尚未进行。
